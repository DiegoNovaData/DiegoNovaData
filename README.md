### About me

Data Engineer with **5+ years of experience** designing and running data platforms — pipeline orchestration, distributed query engines, data quality, and on-prem infrastructure. My skillset is general-purpose data engineering; most of my recent work happens to be **telecom-scale data** (CDR / RAN), but the same patterns — orchestration, schema-on-read at scale, testing, zero-downtime migrations — apply anywhere data volume and infra constraints matter.

**What I work on:**
- 🔀 Orchestration & pipelines — Airflow (TaskFlow API), distributed execution (CeleryExecutor)
- 🗄️ Distributed query engines over object storage — Trino, Hive Metastore, MinIO
- ✅ Data quality & testing — dbt, Great Expectations
- 🏗️ Schema migrations & CI/CD — Alembic / Flyway, GitHub Actions
- 🐳 On-prem infra — Docker / Docker Compose, Kubernetes

**Currently:**
- 🏗️ Building **Telco DataOps Lab** — a self-directed, six-phase project building a KPI analytics platform end to end, with architecture documented as ADRs + C4/Mermaid diagrams. *(→ link once published)*
- 📄 Wrote up the architecture decision behind an on-prem analytics datalake for high-volume network data (MinIO + Trino + Hive Metastore + Airflow) — see [`/docs/adr`](#). *(→ link once published)*
